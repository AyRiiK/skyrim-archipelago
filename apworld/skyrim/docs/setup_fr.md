# Guide d'installation de Skyrim Special Edition

**En cours de développement.** Le mod côté jeu n'existe pas encore ; cet APWorld sert uniquement à générer des parties.

## Prérequis (prévus)

- The Elder Scrolls V: Skyrim Special Edition (Steam)
- [SKSE64](https://skse.silverlock.org/), dans la version qui correspond à ton jeu
- Address Library for SKSE Plugins
- Le mod Archipelago pour Skyrim (à venir)

## Générer une partie

1. Installe `skyrim.apworld` en double-cliquant dessus (ou copie-le dans `custom_worlds`, dans le dossier d'Archipelago).
2. Mets ton YAML dans le dossier `Players` et lance `ArchipelagoGenerate`.
