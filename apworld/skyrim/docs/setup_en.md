# Skyrim Special Edition Setup Guide

**Work in progress.** The game-side mod does not exist yet; this APWorld can only be used to generate seeds.

## Requirements (planned)

- The Elder Scrolls V: Skyrim Special Edition (Steam)
- [SKSE64](https://skse.silverlock.org/) matching your game version
- Address Library for SKSE Plugins
- The Archipelago Skyrim mod (to come)

## Generating a game

1. Install the `skyrim.apworld` by double-clicking it (or copy it to `custom_worlds` in your Archipelago folder).
2. Put your YAML in the `Players` folder and run `ArchipelagoGenerate`.
